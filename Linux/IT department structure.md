# Typical IT department structure
```
IT Department
│
├── Windows System Administrator
│   ├── Active Directory
│   ├── Exchange
│   ├── Group Policy
│   ├── Windows Servers
│   └── File Servers
|   └── DNS (when integrated with Active Directory)
│
├── Linux System Administrator
│   ├── Linux Servers
│   ├── NGINX
│   ├── Apache
│   ├── SSH
│   └── Automation
│
├── Network Engineer
│   ├── Routers
│   ├── Switches
│   ├── DHCP
│   ├── DNS
│   ├── VPN
│   └── Firewalls
│
├── Database Administrator (DBA)
│   ├── PostgreSQL
│   ├── MySQL
│   └── Microsoft SQL Server
│
├── DevOps Engineer
│   ├── Docker
│   ├── Kubernetes
│   ├── CI/CD
│   ├── Cloud
│   ├── Monitoring
│   ├── Infrastructure as Code
│   └── Application Deployment
│
└── Security Engineer
    ├── SIEM
    ├── Vulnerability Management
    ├── IAM
    ├── Compliance
    └── Incident Response
```
